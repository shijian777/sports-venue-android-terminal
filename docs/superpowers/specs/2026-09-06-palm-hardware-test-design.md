# 掌静脉硬件接入：本机验证阶段

承接用户指定最终资料包、先完成可实现部分的授权，以及“可以的，我之前试过”“可以”的确认。此阶段属于新增硬件子系统。沿用已批准的方向，不重复要求用户审批内部工程文档。

## 范围与选择

选择直接集成厂家 AAR，不嵌套安装或启动厂家 APK。相对直接将演示代码复制进 MainActivity，采用独立设备适配器和可单测的会话控制器；相对立即接入生产身份认证，先完成真实采集、临时录入、1:1 比对的本机硬件测试。最终需求要求上传特征，接口只声明 `hand_person_id`，未定义特征上传/本地 ID 同步；因此不能将本机比对结果变成服务器授权或正式会员录入成功。

## 约束

- 保持 Android 7.1.2/API25、1280×800、乾卦品牌；不改变锁板指令、串口所有权、扫码/刷卡、原人脸和还柜行为。MainActivity 仅把 ADMIN 来源布尔值传给录入选择页，并在其生命周期失效路径显式清理掌静脉测试页；审计同步更新其精确文件摘要，不放松审计。
- 本阶段厂商 SDK 仅打入 localDemo。production 不包含掌静脉厂商类或原生库，仍保持现有 fail-closed 身份及业务边界。
- 从既有 localDemo 管理员→人脸/掌纹录入→掌纹入口访问测试。首页功能旗标不因诊断模块而放开。
- 只使用 2.2.17 单一 AAR，SHA256 `33EE6683F382E81F3B3FBB60389FF5B22C8D24CBD0D74D1A21580591E1720D2C`；不混入 2.2.16，不直接运行供应商演示 APK。
- 2.2.17 是随附源码启用版本，不声称它与用户曾测试的旧 APK 完全相同。真机采集、授权、活体、长期稳定性均需终端验证。
- 不执行真实 SDK 激活/硬件采集/开柜/网络业务请求；所有本轮自动化测试使用边界替身或无设备状态。
- 不写盘、不上传、不记录掌静脉图片/特征。仅当前测试页保留一份临时模板，退出/后台/设备掉线/严重错误必须清零。厂商私有缓冲尽力回收，不承诺清除厂商内部不可控副本。
- 不覆盖任一已交付 APK，构建必须显式使用 outputs 内新的 DeliveryRoot。

## 模块与生命周期

`PalmTestController` 是纯 Java 状态机，负责连接、录入、验证、10 秒连接超时、30 秒录入超时、10 秒验证超时、取消和晚到回调。设备操作通过单线程任务队列执行，界面线程不做初始化/比对/停止等待。重复点击不启动重叠任务。断开/取消使旧会话失效，即使 SDK 随后回调也不能改变界面或保留特征。

`JxPalmTestDriver` 只在 localDemo 中通过厂家真实 API 连接 USB、注册监听、采集与单模板比对。初始化失败返回可读错误，不返回模拟成功。捕获图像无需展示或保存，回调图像用完立即 recycle，重复引用只回收一次。应用不显示或记录设备序列号和模板；厂商内部日志不受应用完全控制，不能误把 setShowPrint 称为日志开关。

USB 仅匹配厂家掌静脉设备；其它读卡器、扫码器插拔不能重置掌静脉会话。连接在同一测试页内保持，录入/验证仅切换采集任务。离开测试页/应用后台停止并清理测试模块，不改现有串口连接。该测试生命周期不是最终首页被动监听生命周期。

## 界面

沿用既有选择页的品牌和像素画布，不新增 Activity 或改变主界面。localDemo 的掌纹按钮显示内嵌测试页：状态文字、开始录入、验证刚才的手掌、重新连接、返回。结果明确标注“本机比对，不代表服务器授权”，不跳选柜、不触发还柜。没有设备、权限拒绝、初始化失败、捕获失败、超时、断开均能返回或重试。

production 的同一入口仍使用原未接入提示。生产装配返回空测试模块，不加载厂商 SDK。

## 验收

可重复执行控制器测试覆盖成功、未录入不能验证、低分拒绝、错误码、空/过大特征、重复结果、取消后回调、超时后回调、掉线清零、关闭幂等和连接复用。构建兼容 API25，完整既有测试通过；API25 无 USB 模拟器验证进入测试页、无设备错误、返回和后台清理。产物保留独立目录及摘要。不将上述测试宣称为真机测试或生产掌静脉业务接通。
